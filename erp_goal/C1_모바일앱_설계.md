## 3. 데이터·서버 설계

### 저장 경로 (웹과 코어 한 벌 — 결정 확정)
```
웹:    saveSheetResponsesAction ─ requirePermission(쿠키) ─┐
모바일: /api/mobile/sheet-save ─ requireMobileUser(Bearer) ─┤→ saveSheetResponsesCore
        + canTouchInspection(담당자∪참여자∪manager/admin)   │   (sheet-save-core.ts)
        + 충돌 검사                                          │   범위가드→병렬 삭제/upsert
                                                             │   →stampSheetProtocol
                                                             │   →runAutoCheck(1.4 따라잡기, best-effort)
                                                             │   →syncStepsAndRevalidate(단계+캐시)
```
- Edge Function이 아닌 Next 라우트인 이유: 후속 3종이 Next 코드(next/cache 등)에 묶여 있어 Deno 재구현은 사본 분기 위험. proxy.ts는 `/api/mobile/` 통과·라우트 첫 줄 인증 규약(021482de).
- **충돌 규칙(서버 최신 우선+사용자 확인)**: 요청 rows[].base_updated_at(클라이언트가 마지막으로 본 updated_at, 신규는 null) vs 서버 현재 행. 서버가 더 새롭고 수정자≠나·값 다름 → 그 항목은 저장하지 않고 `conflicts[]`(서버값·수정자·시각) 반환. `force:true` 재요청이 덮어씀.
- **멱등**: 응답 유니크 `(inspection_id,item_code,month)`(125 마이그) → 재전송 무해 = 큐 at-least-once로 손실 0.
- month 축: 외관(X%) 항목만 1~12, 나머지 0 (웹과 동일 — sheet-actions.ts 규칙).

### 항목 마스터 (모바일)
- `inspection_sheets`/`inspection_sheet_items`는 RLS SELECT true(024) → supabase 직접 조회(.range 페이징, 1000행 상한 방어) → AsyncStorage `cache:catalog:v1`(TTL 24h+수동 새로고침).
- 판정 로직은 erp 원본을 mobile/lib로 복사(머리말에 원본 경로): `sheet-scope.ts`(sheetScope·isItemInScope·sheetItemGroupRef), `sheet-facility-map.ts` 발췌(sheetMatchesFacilities 등).

### 오프라인 큐 (Phase D)
- AsyncStorage `offline:queue:v1`: `{opId, kind:'sheet-save'|'step-complete', createdAt, tries, payload:{inspectionId, month, rows[{item_code,result,memo,base_updated_at,editedAt}], clearCodes}}`. 같은 (inspectionId,month) pending은 항목 단위 머지(마지막 터치 승).
- flush: 앱 시작·expo-network 리스너·AppState foreground·수동. FIFO, 성공 확인 후에만 제거. 실패 시 지수 백오프. conflicts는 `offline:conflicts:v1`로 빼서 해결 화면(기본=서버 유지, 덮기=force).
- 읽기 캐시: `cache:planItems:<uid>`·`cache:inspection:<id>`. 화면은 캐시 먼저, 온라인이면 갱신.
- `(app)/_layout.tsx` 로그인 리다이렉트는 명시적 SIGNED_OUT일 때만(오프라인 토큰 리프레시 실패 방어).
