## 2. 규칙 (그룹당 4상태)

그룹 = `DEFECT_GROUPS` 7종(`report9.ts:47`): 소화설비·경보설비·피난구조설비·소화용수설비·소화활동설비·기타·안전시설등.

| # | 조건 | 점검번호 | 불량내용 |
|---|---|---|---|
| ① | 불량 있음 + **사용자 입력 불량명** 있음 | 해당 행의 점검번호 | 사용자 입력값(행별) |
| ② | 불량 있음 + 사용자 입력 전무 | 공란 | **결과참조** (그룹당 1행) |
| ③ | 불량 없음 + 그룹 해당(설치 설비 있음) | 공란 | **이상없음** |
| ④ | 불량 없음 + 그룹 미해당 | 공란 | **해당없음** |

- ①에서 사용자 입력 없는 X행(자동 등록분)은 **개별 인쇄하지 않는다** — "불량내용은 사용자가
  입력한 값"이 요구의 축이고, 점검번호 전체는 첨부 점검표가 원천이다. 사용자 입력 행이 하나라도
  있으면 그 행들만, 하나도 없으면 ②로 접는다.
- ②는 image-61 목업 그대로 점검번호도 공란(중앙 「결과참조」 1행).
- **자리표시자 치유(2026-09-02, `report9-assemble.ts:441-453`)의 항목명 폴백은 이 규칙이 대체**한다:
  이름=코드(정보량 0)·이름 미입력 행이 종전엔 점검표 항목명으로 내려갔는데, 이제 그 자리가
  「결과참조」다. 치유의 목적(코드가 이름 칸에 한 번 더 찍히는 것 방지)은 그대로 달성된다.
- ⚠ `defectRows` **데이터 자체는 불변** — 이행기간 판정(`PLAN_DATE_ROWS`의
  `has`, `xlsx-workbook.ts:839-846)·`actionPlanPeriod`가 이 배열을 읽는다. 41이 바꾸는 것은
  **인쇄 접기(render fold)만**이다. ②그룹도 불량은 있으므로 이행일자는 종전대로 찍힌다(일관).

## 4. 설계

### S1 — 접기 단일 원천 `foldDefectGroups()` (신규, report9.ts 또는 lib)

- **S1-1** `Report9DefectRow`에 `userEntered: boolean` 추가, 조립(`report9-assemble.ts:449-461`)이 새긴다.
  X행: `defectName(code)` 적중이면 true·content=사용자값, 미적중이면 false(content는 종전 항목명
  폴백 유지 — 화면 등 다른 소비처 보호, 인쇄만 접는다). 수기 불량행: 이름≠코드면 true.
- **S1-2** `foldDefectGroups(defectRows, applicableGroups)` → 그룹별
  `{ kind: 'rows'|'refer'|'ok'|'na', rows }`. §2 규칙 ①~④를 여기 한 곳에만 둔다 —
  PDF와 엑셀이 **같은 함수**를 부른다(두 벌이면 한쪽만 갱신돼 조용히 갈라진다).
- **S1-3** 조립이 `applicableGroups: string[]`(해당 그룹 집합)을 산출해 `Report9Data`와
  워크북 파라미터 양쪽에 싣는다(§3 축).

### S2 — PDF 8쪽 적용 (`page8()`)

- **S2-1** 빈 행 분기(`report9.ts:575-578`)를 fold 결과로 교체: `refer`/`ok`/`na`는
  점검번호 공란 + 불량내용 칸 중앙 문구, `rows`는 종전 rowspan 인쇄(단 fold가 준 행만).
- **S2-2** 문구 스타일은 서식 기본(검정·보통) — 목업의 빨강·자간 벌림은 §5 Q-2.

### S3 — 갑지 엑셀 `현5` 적용

- **S3-1** `buildWorkbookValues`의 `DEFECT_GROUP_ROWS` 루프(`xlsx-workbook.ts:853-860`)를 fold
  결과로 교체: `rows`→종전 줄바꿈 접기(상한 `DEFECT_ROWS_PER_GROUP=5`·`defectOverflow` 유지 —
  단 분모가 **fold가 준 행 수**로 바뀐다), `refer`/`ok`/`na`→ `defectContent{row}`에 문구,
  `defectCode{row}`는 null.
- **S3-2** `keepFormulaWhenEmpty`(`xlsx-anchors.ts:214-215,220`)는 존치 — 문구가 실리면 발동하지
  않고, 발동 경로가 남는 그룹(Q-1의 기타 공란 유지 시)에서 계획서!H의 `0` 인쇄를 계속 막는다.
- **S3-3** ⚠ **계획서(별지 10호 엑셀) 시트 전파**: `계획서!H12~H24 = 현5!C4..C10` 수식이라
  이상없음/해당없음/결과참조가 이행조치 사항 칸에도 나타난다 — §5 Q-3.
  이행일자 3칸은 §2의 defectRows 불변으로 종전과 동일(불량 없는 그룹은 공백 유지 — 일관).

### S4 — 검증

- 단위 프로브: fold 4상태 × (사용자입력/자동/혼재) 조립 단언 — 특히 **혼재 그룹**(사용자 1 + 자동 2
  → 사용자 행만)과 **이름=코드 자리표시자**(→ userEntered=false).
- PDF: page8 HTML에서 그룹별 문구·rowspan 단언. 엑셀: `buildWorkbookValues` 맵에서
  `defectCode*`/`defectContent*` 단언 + `defectOverflow` 분모 변경 확인.
- 대조군: 불량·설치·다중이용업이 두루 있는 데이터로 변경 전후 diff — ① 경로(사용자 입력 행)는
  **무변경**이어야 한다.
- tsc 0 + 회귀(report9·workbook 계열 스위트) + Gotenberg 육안 1회(8쪽·현5·계획서 나란히).
