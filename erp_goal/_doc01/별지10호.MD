**미비 검증(missing)** — 경고로만 기록, 생성은 진행. 현행 4종:
1. 이행조치 계획 미입력(0건)
2. 총 이행기간 — 계획 시작일·종료일이 모두 있는 건이 없어 산출 불가 (E10-3)
3. 관할 소방서 미등록 — 제출처가 일반 문구로 인쇄됨 (E10-6)
4. 관계인(대표) 미등록 (E10-6)

(구 '계획 4건 초과' 경고는 행 한도를 폐지하면서 사유가 사라져 제거됨 — 2026-08-12, E10-7)

## 3. 소방계획서_7 작성 화면 매핑 (§4-A-0 입력 3계층)

| 계층 | 별지 10호 항목 | 취급 |
|---|---|---|
| ① 고객 공통 (자동) | 대상물 명칭·구분·소재지, 관계인, 소방안전관리자, 제출처 | 회색 표시 + 원본 수정 링크 |
| ② 점검 건 데이터 (자동) | 이행조치 사항 표(불량별 계획 내용·기간 — defects.action_plan/start/end), 총 이행 기간 자동 산출 | 표로 자동 나열 — 수정은 점검 상세 불량 카드 |
| ③ 서식 고유 값 (**작성 화면에서만 입력** — `annex_inputs` inspection_id × 'report10') | 계획 내용 요약(문서 레벨 — 표 첫 행에 '계획 요약' 태그로 구분 인쇄), 공사업체·예산 메모, 신고인/제출일(report_date 수기 지정), 총 이행 기간 수동 보정 | 신규 입력 |

### 작성 화면 (3단 패턴 — §4-A-2b)

1. **[자동 채움 검토]** — ①② 값 요약 표시. 계획 미입력 불량이 있으면 ⚠ 목록 + 점검 상세(불량 카드) 링크.
2. **[고유 값 입력]** — ③ 항목. 이전 입력 유지(재생성 대응).
3. **[미리보기 · PDF 생성]** — HTML 템플릿(H-6) 렌더 → Gotenberg PDF. 진입점: 문서 작업대(§4-B)·점검 타임라인 ⑤(10호 생성)·별지 서식 그룹 — 화면 1개.

## 4. HTML 이식 시 개선 반영 (H-6·H-23)

| # | 현행 한계 | 개선 |
|---|---|---|
| 1 | 이행조치 표 4행 한도 (HWP 서식 고정) | HTML은 행 동적 생성 — **한도 폐지** (넘치면 자동 페이지 나눔) |
| 2 | 소방안전관리자 = 관계인 대체 | 관계인 role '소방안전관리자'(또는 선임 데이터) 우선, 없으면 대표 폴백 + 화면 ⚠ |
| 3 | report_date = 생성일 고정 | ③ 제출일 수기 지정 (기본값 오늘) |
| 4 | total_period — 시작·종료 누락 시 공란 | 작성 화면에서 누락 안내 + ③ 수동 보정 허용 |
| 5 | 계획 0건이어도 생성 | 작성 화면에서 사전 안내(계획 미입력 불량 목록) — 생성은 막지 않음 |
