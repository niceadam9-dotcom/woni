## 3. 소방계획서_7 작성 화면 매핑 (§4-A-0 입력 3계층)

| 계층 | 별지 9호 항목 | 취급 |
|---|---|---|
| ① 고객 공통 (자동) | 1~2쪽 전부(빠른 입력 18필드·관계인·보험·다중이용업·건축물 현황·자사 정보) + **4~7쪽 세부 현황(`customer_facility_specs` — 별지 4호와 공용 원본)** | 회색 표시 + 원본 수정 링크 |
| ② 점검 건 데이터 (자동) | 점검구분·기간·점검인력 배치, 3쪽 점검결과(√·○×/), **8쪽 불량 세부(설비명·점검번호·불량내용 — defects+시트 점검번호)** | 자동 — 수정은 점검 상세 |
| ③ 서식 고유 값 (**작성 화면에서만 입력** — `annex_inputs` inspection_id × 'report9') | 비고·보완 문구, 보고일 수기 지정, 자동 판정 보정(예: 교육·훈련 실시 체크 수동 확정) | 신규 입력 |

### 작성 화면 (3단 패턴 — §4-A-2b)

1. **[자동 채움 검토]** — ①② 요약 + 누락(missing) 목록·원본 화면 링크 (기존 별지 9호 준비 체크 §9-6⑦ 흡수).
2. **[고유 값 입력]** — ③ 항목. 이전 입력 유지(재생성 대응).
3. **[미리보기 · PDF 생성]** — HTML 템플릿(H-5) 렌더 → Gotenberg PDF. 진입점: 문서 작업대(§4-B)·점검 타임라인 ④·별지 서식 그룹 — 화면 1개.

## 4. HTML 이식 시 개선 반영 (H-5·H-23) — 핵심: 4~8쪽 자동화

| # | 현행 한계 | 개선 |
|---|---|---|
| 1 | **4~7쪽 세부 현황 = 빈 서식** (수기 작성 필요) | `customer_facility_specs`(별지 4호 §4-A와 **공용 단일 원본**)에서 자동 렌더 — 별지 4호 입력 한 번으로 두 서식(4호 3~7쪽·9호 4~7쪽) 완성 |

| 3 | 다중 동(A·B·C동) 병기 양식 | customer_facility_specs building_id 축으로 동별 렌더 (1차는 대표 건물, 다동은 후순위 확장) |

| 5 | 체크 판정 일부 휴리스틱(교육·훈련 등) | 작성 화면 1단에서 판정 근거 표시 + ③ 수동 보정 허용 |
