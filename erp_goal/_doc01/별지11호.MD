## 3. 소방계획서_7 작성 화면 매핑 (§4-A-0 입력 3계층)

| 계층 | 별지 11호 항목 | 취급 |
|---|---|---|
| ① 고객 공통 (자동) | 대상물 명칭·구분·소재지, 관계인, 소방안전관리자, 점검업체(자사), 제출처 | 회색 표시 + 원본 수정 링크 |
| ② 점검 건 데이터 (자동) | 이행조치 내용 표(불량별 조치결과·완료일), 전/후 사진(첨부 패키지) | 표로 자동 나열 — 수정은 점검 상세 불량 카드 |
| ③ 서식 고유 값 (**작성 화면에서만 입력** — `annex_inputs` inspection_id × 'report11') | 완료 보고 문구(비고·보완), 신고인/제출일(report_date 수기 지정), 증빙 목록 메모, 4건 초과 시 표기 우선순위 선택 | 신규 입력 |

### 작성 화면 (3단 패턴 — §4-A-2b)

1. **[자동 채움 검토]** — ①② 값 요약 표시. 소방안전관리자가 관계인 대체 상태면 ⚠ 안내(§2 개선: 선임 데이터 연결).
2. **[고유 값 입력]** — ③ 항목. 이전 입력 유지(재생성 대응).
3. **[미리보기 · PDF 생성]** — HTML 템플릿(H-6) 렌더 → Gotenberg PDF. 진입점: 문서 작업대(§4-B)·점검 타임라인 ⑥·별지 서식 그룹 — 화면 1개.

## 4. HTML 이식 시 개선 반영 (H-6·H-23)

| # | 현행 한계 | 개선 |
|---|---|---|
| 1 | 이행조치 표 4행 한도 (HWP 서식 고정) | HTML은 행 동적 생성 — **한도 폐지** (넘치면 자동 페이지 나눔). 서식 모양 유지 범위에서 |
| 2 | 소방안전관리자 = 관계인 대체 | 관계인 role '소방안전관리자'(또는 선임 데이터) 우선, 없으면 대표 폴백 + 화면 ⚠ |
| 3 | report_date = 생성일 고정 | ③ 제출일 수기 지정 (기본값 오늘) |
| 4 | 완료 0건이어도 생성 | 작성 화면에서 사전 안내 (⑤ 조치 미완료 건 목록 + 점검 상세 링크) — 생성은 막지 않음 |
