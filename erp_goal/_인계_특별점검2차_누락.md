# 재발 방지 (사용자 요청 2026-09-01 — 구현하지 않고 인계만)

## 이 결함의 정체: '계획'과 '집행' 사이의 이음매

순수 함수가 **요청서**(`needCreate`)를 발행했는데, 집행부가 그걸 **읽지 않아도 아무도 모르는** 구조였다.
검사는 요청서가 잘 쓰였는지만 봤고 이음매엔 검사가 없었다.
같은 함정의 전례: 「[／ 전체]가 ○로 인쇄」(구성 지점 3곳 중 1곳 누락) · 「보내지 않으면 실리지 않는다」(부분 업데이트)
· 오늘 점검표 롤업 축(선택 인자였으면 호출부가 조용히 옛 동작으로 남았을 것).
**전부 "한쪽은 옳은데 그걸 받는 쪽이 없다"이다.**

## ① 컴파일러가 막게 한다 — 가장 강함(사람이 기억할 필요 없음)

`needCreate`를 **별도 배열로 뺀 것**이 근본 원인이다. 이름은 "만들어 달라"는 요청인데 타입은 그냥 배열이라
**무시해도 컴파일이 통과**한다. op 유니온에 합치고 exhaustive로 소진시키면 빠뜨리는 순간 **빌드가 깨진다**:

```ts
type SlotOp =
  | { kind: 'toSpecial'; … }
  | { kind: 'toMonthly'; … }
  | { kind: 'create';    … }        // ← 요청서를 op로 승격
for (const op of plan.ops) {
  switch (op.kind) {
    case 'toSpecial': …; break
    case 'toMonthly': …; break
    case 'create':    …; break
    default: { const _never: never = op; void _never }   // 새 종류 누락 = 컴파일 오류
  }
}
```

## ② 결과 불변식을 집행부 안에 박는다 — 한 줄, 즉시 적용 가능

`ReconcileResult`가 `needCreate`와 `created`를 **둘 다** 세고 있으므로 모순을 스스로 말할 수 있다:

```ts
if (out.needCreate > 0 && out.created === 0) {
  out.notes.push(`⚠ 생성 필요 ${out.needCreate}건인데 0건 생성 — 요청서가 버려졌다`)
}
```

이번 결함은 이 한 줄이면 **첫 실행에서 노출**됐다. 값을 세면서 **값들 사이의 관계**를 안 본 것이 놓친 지점이다.

## ③ 단언의 축을 '출력'에서 '최종 상태'로

`test-special-slot`은 *함수가 뭘 계획했나*를 본다 — 경로 축이라 경로가 하나 빠지면 볼 수 없다.
짝이 되어야 할 검사는 **재계산을 실제로 돌린 뒤 "계획의 모양이 desired와 같은가"**다.
교체로 됐든 생성으로 됐든 무관하게 *끝난 뒤의 상태*를 묻기 때문에 **어느 경로가 빠져도 빨강**이 된다.
(DB에 붙는 검사 선례: `test-sheet-overview`.)

## ④ 데이터 축 불변식 — 경로와 완전히 무관한 그물

`check-data-invariants`에 한 줄이 가장 값싸고 오래 간다:

> **INV-D13** 종합 대상 고객의 각 연도에 `special_작동(seq=2)`이 정확히 1건

코드가 어떻게 바뀌든 어느 경로로 깨지든 잡힌다. pre-push에서 비차단 경고로 돌아 개발 흐름도 안 막는다.
⚠ **켜기 전에 위반 건수를 먼저 셀 것** — 기존 데이터가 대량 위반이면 경고가 소음이 되어 아무도 안 본다.

## ⑤ 검사 문구 규칙 — "못 한다"를 초록으로 단언하지 말 것

```
✅ 12월 2차는 needCreate로 나온다(교체로는 못 만든다)      ← test-special-slot.mts:81
```

이 문장이 **결함을 사양으로 승격**시켰다. 한계를 초록으로 박아두면 그게 *중간 상태*인지 *최종 상태*인지
검사가 말하지 않는다.

> **규칙: 부정형·한계를 단언하는 검사에는 반드시 "그럼 누가 하는가"를 단언하는 짝 검사를 붙인다.
> 짝이 없으면 그 초록은 결함의 알리바이가 된다.**

여기선 `needCreate로 나온다` 옆에 **`그리고 그것이 실제로 생성된다`**가 있었어야 했다.
