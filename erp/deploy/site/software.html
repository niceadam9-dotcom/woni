점검 일정부터
소방서 제출까지 한 화면

점검업체가 직접 쓰려고 만든 프로그램입니다. 법정 점검 시기와 보고 기한을 자동으로 계산하고, 별지 서식과 소방계획서를 점검 기록에서 바로 만들어 냅니다.

데모 신청 기능 보기

이런 일이 줄어듭니다

  • ✓달력에 점검 시기를 손으로 옮겨 적는 일
  • ✓별지 서식에 같은 내용을 다시 타이핑하는 일
  • ✓보고 기한 15일·이행 기한을 놓치는 일
  • ✓현장에서 종이에 적고 사무실에서 다시 입력하는 일
주요 기능

점검 한 바퀴를 그대로 옮겼습니다

점검업체가 실제로 일하는 순서대로 화면을 만들었습니다.

점검 달력

법정 점검 시기를 자동으로 잡습니다

사용승인일을 넣으면 종합점검과 작동점검 달이 계산되어 달력에 올라갑니다. 주말과 공휴일은 다음 영업일로 밀어 줍니다.

  • 고객별 점검 일정·담당자 배정
  • 점검 전 관계인 안내 문자
  • 보고 기한 임박 경고
일월화수목금토
6단계 점검

점검표에서 이행 완료까지 단계별로

점검표 → 결과 보고 → 관계인 보고 → 소방서 제출 → 이행계획 → 이행완료. 각 단계의 완료 조건과 마감일이 화면에 보입니다.

  • 불량이 없으면 이행 단계는 자동으로 감춤
  • 단계마다 남은 기한 표시
① 점검표② 결과 보고③ 관계인 보고④ 소방서 제출
법정 서식

별지 9·10·11호와 소방계획서를 자동으로

점검 기록이 그대로 서식에 들어갑니다. 소방시설 민원센터에 올릴 한글(HWPX) 파일도 만들어 줍니다.

  • 점검결과보고서·이행계획서·이행완료보고서
  • 소방계획서 엑셀·PDF
  • 자체점검 기록표 게시물
별지 9호별지 10호별지 11호소방계획서
모바일 점검표

지하 기계실에서도 끊기지 않습니다

휴대폰으로 점검표를 입력합니다. 전파가 안 잡히는 곳에서 입력한 내용은 휴대폰에 쌓였다가 연결되면 자동으로 올라갑니다.

  • 오프라인 입력·자동 동기화
  • 설비 QR을 찍으면 이력 바로 확인
